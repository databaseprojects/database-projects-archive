# Plan view, downhill at bottom (test render)

Castle Mountain Resort only. Not wired into the site.

- castle-mountain-resort-downhill.png: plan view turned 241.1° so the uphill bearing points up the page (summit at top, base at bottom).
- Angle: computed, not hand-set. Castle has no hand-set bird's-eye facing (it uses the automatic one, which looks uphill), so the uphill bearing was taken from the lifts' bottom-to-top direction, weighted by length (10 of 12 lifts agree).
- Drawn from the existing plan data: contours (alberta contours), runs and lifts (alberta.json). No tree wash, caption band or frame.
